<h1 className="h1">TS docs: <em>«стилистический выбор»</em></h1>

<div className="code code-sm">
```typescript
// как описывать объекты в TS ?
// В TS оба варианта почти эквивалентны:
interface Point { x: number; y: number; }
type Point = { x: number; y: number; };

// Интерфейс может описывать функцию:
interface MyFn { (): void; }
// и Тип может описывать функцию:
type MyFn = () => void;
```
</div>

<div className="callout">
  <div className="lead">и если в TypeScript разница минимальна</div>
  <div className="sub">то в JavaScript runtime она вообще <span className="pink">исчезает!</span></div>
</div>

<h1 className="h1"><em>Пример</em> различия</h1>

<div className="code code-sm">
```typescript
// Interface содержит в себе и "до" и "после":
interface Factory {
    // " до " : с какой сущностью
    new (config: Config): Instance;
    // " после " : что можем делать
    create (): Product;
}
// Type — просто описание структуры сущности:
type Config = {
    name: string;
    count: number;
};
```
</div>
