# POJO с прототипом

<div className='codemedium'>

```javascript
// POJO — обычный объект (Type)
const someObject = {
    name: 'myType',
    createdAt: new Date()
};
// Но мы можем добавить Interface!
Object.setPrototypeOf(someObject, {
    describe () {
        return `Type ${this.name} created at ${this.createdAt}`;
    }
});
console.log(someObject.describe());  // работает!
```

</div>

<div className="slide-callout">
<h3 className="secondary">Type получил Interface через прототип!</h3>
</div>

-----

# Тот же результат через Constructor

<div className='codemedium'>

```javascript
// Constructor — это Interface
function Interface(name) {
    this.name = name;
    this.createdAt = new Date();
}
// но мы можем добавить тип
Interface.prototype.describe = function() {
    return `Interface ${this.name} created at ${this.createdAt}`;
};
const myInstance = new Interface('MyInterface');
console.log(myInstance.describe());  // тот же результат!
```

</div>

<div className="slide-callout">
<h2 className="secondary">POJO + setPrototypeOf === new Constructor</h2>
</div>

# А как в TypeScript?

<div className='codemedium'>

```typescript
type MyType = {
    name: string;
    createdAt: Date;
};
interface MyInterface {
    describe(): string;
}
type MyInstance = MyType & MyInterface;
interface MyCtor extends NewableFunction {
    new(name: string): MyInstance;
    prototype: MyInterface;
}
```

</div>

<div className="slide-callout">
<h3 className="secondary">Type — структура, Interface — поведение, &amp; — объединение</h3>

# Что такое NewableFunction в TypeScript?

<div className='codemedium'>

```typescript
// Встроенный тип TS — НЕ для прямого использования!
interface NewableFunction {
    new (...args: any[]): any;
    prototype: any;
}

// НЕЛЬЗЯ: просто присвоить — потеряем прототип
const ctor: NewableFunction = function() {};
// ctor.prototype — any, не расширяется!
```

</div>

<div className="slide-callout">
<h3 className="secondary"><code className="inlineCode">NewableFunction</code> — интерфейс-заглушка, не тип для конструкторов</h3>
</div>

-----

# логично использовать через <code className="inlineCode">extends</code>

<div className='codemedium'>

```typescript
// Declaration merging + extends = работающий прототип
interface MyConstructor extends NewableFunction {
    new (): MyInstance;
    prototype: MyProto;
}

// Теперь можем типизировать:
interface MyProto {
    shared: string;
}
interface MyInstance extends MyProto {
    own: number;
}
```

</div>

<div className="slide-callout">
<h3 className="primary"><code className="inlineCode">extends</code> активирует declaration merging для прототипа</h3>
</div>
