<h1 className="h1"><code className="ic">await</code> <em>new</em></h1>

<div className="code">
```javascript
class MyPromise extends Promise {
    constructor(handler) { super(handler); }
}
const myItem = new MyPromise((resolve) => { resolve(123); });
// Мы можем await-ить результат new!
console.log(await myItem);  // 123

// И проверить наследование:
console.log(myItem instanceof Promise);  // true
```
</div>

<div className="callout">
  <div className="lead"><code className="ic">new</code> + <code className="ic">await</code> === <em>новая семантика!</em></div>
</div>

-----

<h1 className="h1"><em>запустим</em> и посмотрим</h1>

<div className="code">
```javascript
class MyPromise extends Promise {
    constructor(handler) { super(handler); }
}
// new возвращает thenable
// await автоматически разворачивает его
console.log(await new MyPromise((resolve) => {
    resolve(321);
}));  // 321
// Граница между sync и async construction размыта
```
</div>

<h1 className="h1"><em>можно</em> и без Promise</h1>

<div className="code">
```javascript
class MyAsyncClass {
    constructor() {
      const self = this;
      return new Promise((resolve) => {
            setTimeout(() => {
                item.field = 123;
                resolve(self);
            }, 1000);
        });
    }
}
```
</div>

-----

<h1 className="h1"><em>можно</em> и без Promise</h1>

<div className="code">
```javascript
class MySubAsyncClass extends MyAsyncClass {
    constructor() {
        const promise = super();
        return new Promise(async (resolve) => {
            // тут item содержит  this
            const item = await promise;
            console.log(item.field); // 123
            resolve(item);
        });
    }
}
```
</div>

-----

<h1 className="h1"><em>запустим</em> и посмотрим</h1>

<div className="code">
```javascript
( async () => {

    // создадим ожидание наследника
    const successor = new MySubAsyncClass;

    // создадим сам экземпляр наследника
    const item = await successor;

    // проверим, что всё получилось 
    console.log(item.field); // 123
} )();
```
</div>

<h1 className="h1">а <em>как в TypeScript?</em></h1>

<div className="code">

```typescript
interface AsyncConstructor<T> extends NewableFunction {
    new (...args: any[]): Promise<T>;
}
class MyPromise<T> extends Promise<T> {
    constructor(executor: (
      resolve: (value: T) => void, reject: (reason?: any) => void
    ) => void) { super(executor); }
}
// await new — тип выводится как T, не Promise<T>
const item: number = await new MyPromise((resolve) => resolve(123));
```
</div>

<div className="callout">
  <div className="lead">constructor получает <code className="ic">Promise{'<T>'}</code>
   — <code className="ic">await</code> отдаёт <span className="pink">T</span></div>
</div>
